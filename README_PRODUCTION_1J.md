# Ebbing Tides Production 1J — Asterian Captain Candidate

Apply this overlay to the current public Git build at commit `076a7fc` or a later compatible build by extracting it into the project root and allowing matching files to replace their previous versions.

## What it changes

- Enables the Asterian culture pack on the Captain screen.
- Reuses the accepted Production 1I warm-ivory, oxblood, bronze, and restrained-blue visual language.
- Fits the painted frame to the sticky Captain dossier and to each scrolling chapter independently.
- Adds distinct Asterian paintings to the History, Capabilities, and Condition header wells.
- Reuses the accepted Asterian register-tab treatment for Captain accordions.

## What it does not change

- Character Creator geometry or accepted Production 1I presentation.
- Captain data, progression, injury, relationship, or standing mechanics.
- Navigation, naval combat, audio, save schema, or any unrelated system.
- Unimplemented culture packs, which continue to use the neutral fallback.
