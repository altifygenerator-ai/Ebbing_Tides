# Ebbing Tides Alpha 0.6D — RPG R1.2

R1.2 is the final small readability/alignment cleanup requested after live inspection of R1.1.

Changes are deliberately limited to three issues:

- The paired Captain Sheet accordion headers use matching desktop geometry, and the longer `People Who Know You` title no longer wraps onto a second line at normal desktop widths. Narrow layouts may wrap normally.
- Specialization skill/bonus text, including values such as `Seamanship +6`, uses darker parchment-ink contrast.
- Character Creator Homeland / Culture / Faith labels and values beneath the portrait use darker parchment-ink contrast instead of the older dark-panel color assumptions.

No reputation, relationship, law, crime, warrant, or save-system mechanics changed. Save schema remains v12.

The next planned step is an R2 design discussion before any implementation of smuggling, customs, privateering, Letters of Marque, contraband, or war authorization.
