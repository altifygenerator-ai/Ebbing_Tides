# Ebbing Tides Alpha 0.6D — R2
## Dynamic Trade Law, Customs, Smuggling, Privateering & Wartime Law

Base: accepted A0.3C plus the R2 Readiness Review gate.  
Package: `0.6.0-alpha.d.r2`  
Save schema: v12 (unchanged).

R2 consumes the systems repaired during A0 rather than creating parallel owners:

- jurisdiction baseline trade policy + A0.3C live policy/world-cause tags determine current cargo legality;
- customs permits are persistent, time-limited credentials issued by competent local authority;
- arrival customs inspections derive from port customs capacity, cargo, standing/heat, warrants and live search policy;
- concealment / black-market trading use captain skills and local smuggling access;
- discovered smuggling/customs offenses feed the existing A0.2D crime/evidence/report lifecycle and R1 warrants;
- letters of marque exist only while an A0.3C policy actually authorizes privateering and name the currently authorized enemy factions;
- commissioned prize-taking reuses the A0.1A defeated-vessel/prize lifecycle rather than creating a second capture/prize system;
- lawful/privateer wartime posture consumes current world policy and active known legal state rather than universal hostility;
- Market / Government / Arrival presentation stays compact and text-first. There is no customs/crime strategy dashboard.

Skeldra remains the proving ground. No broader world activation is included in this pass.
