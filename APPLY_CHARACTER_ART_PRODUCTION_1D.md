# Apply — Character Creator / Captain Reference-Locked Production 1D

## Required base

Apply over the current accepted R2 project with **Character Creator / Captain Purpose-Painted Lock 1C** already installed.

## Install

Extract this overlay into the Ebbing Tides project root and replace matching files.

Then run:

```powershell
npm run typecheck:alpha
npm run alpha:build
npm test
npm run alpha:art-layouts
```

Expected results:

- TypeScript: PASS
- Alpha build: PASS
- full suite: **473 / 473 PASS**
- art layouts: **2 / 2 PASS**

## Manual visual acceptance

Inspect the actual runtime at normal desktop size.

The pass should be accepted only if:

- the Character Creator feels housed inside the Skeldran art rather than laid over a full-screen picture;
- the tan center reads as a manuscript surface and all controls/text remain easy to read;
- the culture banner / lantern and harbor / chart artwork remain in genuine unused areas;
- the Review step's harbor illustration does not collide with its dynamic summary;
- the Captain page keeps live records/code ownership while the painted header, manuscript, portrait, and trim create the richer visual hierarchy;
- Old Gods and Covenant change only the secondary religion accent;
- no other game screen changes appearance.

The package includes actual runtime screenshots under `docs/visual-qa/character-art-production-1d/` for comparison.
