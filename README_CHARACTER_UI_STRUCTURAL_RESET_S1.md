# Character UI Structural Reset / Pre-Art S1

This package exits the rejected manuscript-skin iteration loop. It keeps the useful character-facing functionality from Character/RPG Pass 1 while stripping the active painted-manuscript presentation back to clean code-owned structure.

This is **not** the final UI lock and **not** an art pass. Its purpose is to establish a reliable structural baseline that can absorb the real Reputation / Relationships / Law / Smuggling / Privateering systems before final geometry is approved and painted presentation is authored around it.
