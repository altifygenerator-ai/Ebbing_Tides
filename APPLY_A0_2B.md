# Apply Alpha 0.6D A0.2B — Progression Cadence / Anti-Farming Repair

Apply this overlay directly over **A0.2A** (`0.6.0-alpha.d.a0-2a`).

1. Back up the A0.2A project.
2. Extract this overlay over the project root, preserving paths and replacing matching files.
3. Confirm `package.json` reports `0.6.0-alpha.d.a0-2b`.
4. Save schema remains **v12**. Existing v12 saves normalize the deprecated finite recent-key queues on load; new time-based cadence data is additive within existing JSON advancement/practice state.
5. No Supabase migration is required for this pass because normalized character progression is already stored in JSONB fields that accept the additive cadence shape.
6. Run:
   - `npm run typecheck:alpha`
   - `npm run alpha:build`
   - `npm test`
   - `npm run alpha:art-layouts`

No structural visual approval is required. Accepted R1.2 presentation geometry is unchanged. Deck Drill now advances two hours of the existing world clock, so visible time/date and downstream simulation may legitimately advance when training begins.

A0.2B deliberately does **not** change prepared-ability semantics, Arcane Strain recovery, or navigation-preparation consequences; those remain A0.2C.
