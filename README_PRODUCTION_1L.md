# Ebbing Tides Production 1L — Serathi Captain Candidate

Apply this overlay over the current Git build or the Production 1K.1 Serathi Creator candidate by extracting it into the project root and allowing matching files to replace their prior versions.

## What it changes

- Enables the corrected Serathi culture pack on the Captain screen.
- Reuses the accepted limestone, cedar, copper, terracotta, and sparse colored-glass material family.
- Fits the frame independently to the sticky portrait dossier and each scrolling Captain chapter.
- Uses Serathi regional art in existing profile and chapter-header wells.
- Uses the corrected Serathi register skin for existing Captain accordions.

## What it does not change

- The accepted Skeldran, Asterian, or Serathi Creator treatments.
- Captain mechanics, data, progression, relationships, injuries, or standings.
- Navigation, naval combat, audio, saves, or unrelated screens.
