# Ebbing Tides Production 1K — Serathi Creator Candidate

Apply this overlay to the current public Git build at commit `076a7fc` or a later compatible build by extracting it into the project root and allowing matching files to replace their previous versions.

## What it changes

- Enables the Serathi Salt-Limestone Ledger culture pack in Character Creator.
- Uses irregular warm limestone lintels, dark cedar uprights, square copper straps, terracotta tesserae, and sparse indigo/sea-green glass accents.
- Removes the starbursts, round medallions, and continuous blue wave rails that made the first candidate too close to Asterian.
- Fits a transparent painted frame to the existing central manuscript, portrait, and decorative cells without making the art own screen geometry.
- Fits a terracotta register skin to the six existing Creator step buttons.
- Uses existing Serathi regional paintings only in the current decorative image wells.
- Keeps the responsive exterior perimeter code-owned so the frame is never stretched across the viewport.

## What it does not change

- The accepted Skeldran and Asterian culture treatments.
- Captain presentation; Serathi Captain remains gated until this Creator candidate is visually approved.
- Character rules, content, navigation, naval combat, audio, saves, or unrelated systems.
- Covenant faith presentation; no flame or invented secular emblem is used as generic Serathi ornament.
- Asterian's polished civic-enamel, brass-sun, and wave-band vocabulary.
