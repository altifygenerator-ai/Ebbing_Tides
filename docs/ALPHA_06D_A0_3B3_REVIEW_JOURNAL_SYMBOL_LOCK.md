# Alpha 0.6D A0.3B3 — Review / Journal / Character Symbol Lock

## Scope

A0.3B3 responds to live visual review of A0.3B2. The pass changes presentation ownership only where the current code-owned UI was clipping, misaligning repeated journal rows, or carrying unwanted identity-symbol clutter.

## Creator Review

The creator shell remains fixed. The Review pane now gives its dynamic review body the scroll ownership instead of relying on overflow beyond the locked center pane. The page title remains stable while the complete starting toolbox and consequence summary can be scrolled. Redundant summary copy was removed, and unique starting abilities/specializations/schematics are surfaced before the strongest-skill rollup.

## Journal

The left and right physical pages now use the same fixed heading-band height. The right page does not duplicate the section heading; it uses the same structural band only to carry restrained captain metadata. Because both pages reserve identical header geometry, the two entry rows on each side share vertical baselines again. Later folios continue to derive `<Section> · Continued` from the active Journal tab label, so the rule applies to What I Know, Contacts, Promises & Work, Standing & Law, and What Happened.

## Character presence symbols

Portraits and relationship state remain the meaningful visual identity on People and conversation cards. The small main-identity mark strip is removed from those two surfaces only. This does not remove the underlying ancestry/religion/homeland/affiliation data or change symbol use in unrelated contexts.

## Persistence / systems

Save schema remains v12. No persistent state changes, migrations, economy changes, law changes, progression changes, NPC-planner changes, or learning-source changes are introduced.
