# Alpha 0.6D RPG R1.2 — Final Readability / Alignment Cleanup

R1.2 is intentionally narrow. It closes three visual issues found during live R1.1 inspection before the R2 design discussion.

## Locked corrections

1. **Paired accordions remain symmetrical.** The `Known Powers` and `People Who Know You` headers use the same desktop summary-band geometry. The longer relationship title stays on one line at normal desktop widths; narrow layouts may wrap naturally.
2. **Specialization bonus text is readable.** Skill/bonus strings such as `Seamanship +6` use dark parchment ink rather than the overly pale prior treatment.
3. **Creator identity summary is readable.** `Homeland`, `Culture`, and `Faith` labels and values below the portrait now use dark parchment-appropriate contrast.

No gameplay, standing, law, crime, warrant, relationship, or save-state mechanics change in this pass. Save schema remains v12.
