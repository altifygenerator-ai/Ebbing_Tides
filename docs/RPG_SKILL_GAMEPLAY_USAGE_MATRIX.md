# Ebbing Tides — RPG Skill Gameplay Usage Matrix

Status: **Alpha 0.6D character-RPG baseline.** This document is permanent design guidance for keeping the six attributes and eighteen skills consequence-driven rather than dashboard-driven.

## Product rule

A rating does not count as RPG depth by itself. A skill earns its place when it changes what the captain can notice, understand, attempt, or solve. Prefer alternate information, choices, approaches, and consequences over generic percentage bonuses.

Player-facing checks should often be implicit. When the character simply knows something because of training or background, surface the useful knowledge rather than a bracketed check label.

## Attributes

| Attribute | Meaningful gameplay uses |
|---|---|
| Might | heavy melee and grappling; forcing/breaching; hauling/rescue; resisting physical exhaustion; intimidating through physical presence when appropriate |
| Agility | blades and firearms handling; balance on a moving deck; boarding movement; evasive ship/personal actions; delicate physical work |
| Perception | spotting ships/signs; navigation and weather reading; gunnery aim; noticing deception or danger; finding environmental clues |
| Intellect | engineering diagnosis; medicine; scholarship and document analysis; Arcane theory; planning/technical problem solving |
| Will | Arcane control; pain/stress/fear resistance; maintaining concentration; enduring hardship; resisting coercive or supernatural pressure |
| Presence | persuasion; command; recruitment; negotiation; intimidation; diplomacy and social authority |

## Background and profession consequence baseline

Character origin choices are not flavor-only metadata. Alpha 0.6D now uses background/profession to select a captain's natural port-reading lens:

- merchant experience -> Commerce / exchange insight
- navigator, sailor, marine, gunner, former naval midshipman -> maritime/navigation insight
- foundry/engineering/shipwright experience -> engineering/yard insight
- smuggler upbringing/profession -> Streetwise/back-channel insight
- temple/scholar/priest backgrounds -> Scholarship/institutional insight
- other builds -> social/Persuasion observation

Starting knowledge already differs by naval/sailor, foundry/engineering, merchant, smuggler and religious origins. These differences remain player knowledge, not world truth.

## Current 0.6D proof points

The following are already wired into actual play rather than only documented:

- Navigation + Perception: voyage prep, detection, Search Waters and encounter observation.
- Seamanship + Agility: avoidance, pursuit/escape and naval maneuvering.
- Gunnery + Perception: naval fire.
- Engineering + Intellect: damage control and technical character-build paths.
- Commerce + Presence: transaction checks; Commerce also controls how much actionable market state is summarized.
- Streetwise/Persuasion + Presence: rumor gathering.
- Command + Presence: surrender and zero-supply crew-hardship mitigation.
- Background/profession: starting knowledge and the new contextual port-reading action.
- Blades/Firearms/Athletics: personal combat foundation.
- Arcana/technical abilities: learned practices with derived specialization rather than a player-managed Attunement slider.

## Expansion discipline

Future content should consult this matrix before adding a new visible skill display. New encounters/contracts should prefer two or more valid approaches where the fiction supports them. Do not manufacture filler checks solely to make every skill appear every hour.
