# Production 1I — Asterian Character Creator Candidate

Base: public Git commit `c358ee0`

## Scope

This candidate implements only the Asterian Character Creator presentation. It does not modify the accepted Skeldran pack. Asterian Captain remains on the neutral structural fallback until a separate Captain composition is measured, designed, implemented, and visually approved.

## Approved direction

- warm ivory and sun-aged white stone dominate;
- wine red and oxblood own the rail, side panel, and register leaves;
- aged bronze is limited to joints and fasteners;
- Mediterranean blue is only a narrow maritime accent;
- one continuous transparent image owns the entire center manuscript surround;
- the joined surround and register leaves use nine-slice rendering so their corners and ornaments keep their painted proportions;
- the manuscript interior uses a purpose-built blank texture with no embedded mockup text;
- the responsive exterior perimeter stays code-owned, using a quiet bronze seam and oxblood falloff instead of stretching frame art across the viewport;
- regional paintings remain inside existing lower decorative wells;
- code continues to own every control, row, label, scroll area, and layout measurement.

## Explicitly rejected

- checkerboard pixels or simulated transparency;
- independently generated lintel, sill, and stile pieces;
- Asterian assets forced through Skeldran alpha masks;
- shared Skeldran/Asterian selectors or art paths;
- decorative bars crossing live headings or controls;
- scaling Creator artwork into Captain geometry.
