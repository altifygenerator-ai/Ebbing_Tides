Ebbing Tides Named Ship Tokens Package
=====================================

Contents:
- Named_Ship_Tokens/: full-size transparent token assets
- Named_Ship_Tokens_128px/: 128x128 gameplay-scale exports
- Named_Ship_Tokens_96px/: 96x96 gameplay-scale exports
- Named_Ship_Tokens_64px/: 64x64 gameplay-scale exports
- TOKEN_MANIFEST.csv: labels and usage mapping

Notes:
- These tokens were derived from the approved named ship reference set.
- Labels follow the same ship order and naming logic as the prior named ship package.
- Transparency is preserved.
- These are intended for world/regional map use, not as full ship reference art.
