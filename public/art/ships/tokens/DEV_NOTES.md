# Ebbing Tides — Named Ship Tokens

This package contains tokenized versions of the current named-ship set.

## Source Relationship
- Each token is intended to represent the same vessel identity as its corresponding full ship reference art.
- Token silhouettes emphasize gameplay readability while preserving hull family, mast count, and broad regional identity.
- No additional lore, builders, ports of origin, crests, or refits were invented in the packaging step.
